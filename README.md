# Web senzilla per planificar-se una rutina setmanal
Simplement una web estàtica feta amb vanilla javascript i css que et permet dissenyar un horari a seguir al llarg d'una setmana.

### Coses xules implementades
- Mode fosc i mode clar
- Diferents paletes de colors a triar
- Mobile responisve
- Pots amagar o mostrar el cap de setmana. Pots seleccionar quina franja horària mostrar
- Pots compartir la teva rutina o agenda setmanal via URL (és un JSON codificat en base64 i afegit com a paràmetre a la query string)
